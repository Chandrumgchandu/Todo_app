# Todo App Frontend

A small static frontend Todo project used as a UI and JavaScript practice exercise.

This repository is intentionally simple and belongs in the experimental/supporting category of the portfolio. It should not be presented as a production application.

## What is included

```text
frontend/index.html
frontend/css/style.css
frontend/js/script.js
```

## How to run

Open `frontend/index.html` in a browser, or serve the folder with any static file server.

Example:

```bash
cd frontend
python -m http.server 8000
```

Then open `http://localhost:8000`.

## What this demonstrates

- Basic HTML, CSS, and JavaScript structure
- Simple client-side interaction
- Frontend project organization
